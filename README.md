# login-page
# 🔐 Projeto Login Page

Projeto desenvolvido durante o **Curso de HTML5 e CSS3** do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O objetivo deste projeto foi desenvolver uma interface moderna de login utilizando **HTML5** e **CSS3**, com foco em responsividade, organização do layout e boas práticas de desenvolvimento front-end.

---

## 🚀 Demonstração

> *(https://eijhenyfer.github.io/login-page/)*

---

## ✨ Funcionalidades

* 🔐 Interface de login moderna
* 📱 Layout totalmente responsivo
* 📧 Campos para e-mail e senha
* 🎨 Design limpo e intuitivo
* 🖱️ Efeitos visuais em botões e campos de formulário
* 💻 Compatível com diferentes tamanhos de tela

---

## 📚 Conceitos praticados

```bash id="1v2jgx"

```

3. Execute o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.

---

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para praticar a criação de interfaces de autenticação modernas, aplicando conceitos de formulários HTML, estilização com CSS3, responsividade e organização do código para proporcionar uma boa experiência ao usuário.

> **Observação:** Esta é uma interface estática desenvolvida para fins de estudo. Ela não possui autenticação ou integração com um back-end.
